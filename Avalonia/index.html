    Avalonia 桌面开发¶

    面向 .NET 8 / Avalonia 11 的跨平台桌面 UI 工程知识地图，重点服务信创 Linux 上的工业上位机开发。

    本组记录使用 Avalonia 11 构建西门子 PLC 上位机过程中的 UI 层实践：从 MVVM 分层、数据绑定、自定义控件到页面导航，并以 SukiUI 6.x 作为主题控件库。内容默认读者已熟悉 C# / .NET 8，不解释语言基础，而聚焦绑定模型、渲染管线，以及 Linux / 银河麒麟 V11 下的字体、DPI、输入法、软件渲染与自包含发布等工程细节。通信侧坚持通用报文协议，UI 层只依赖抽象接口，避免与厂商专有协议绑定。涉及 SukiUI 与 Avalonia 的具体 API，均以当前安装版本的 XML 注释和 Demo 为准。

    示例只表达工程结构与绑定 / 绘制模式，不承诺任何具体版本行为；页面之间用相对路径互链，便于整组离线阅读与检索。

    学习路径¶

    1. 先读 MVVM 与 数据绑定，把 ViewModel、命令、绑定模型与编译期绑定（x:CompileBindings）跑通，这是后面所有页面的地基。
    2. 再按 自定义控件 把寄存器仪表、告警灯、趋势曲线做成可复用控件，避免把业务逻辑堆进 AXAML。
    3. 用 页面导航 组织「总览 / 参数 / 报警 / 日志」多页面 HMI，确定 ViewModel 优先的区域切换方案。
    4. 对照 SukiUI 配置主题、窗口与 Host，并把明暗切换、Toast 接入现有 ViewModel。
    5. 最后结合 Kylin V11 做字体、输入法、渲染与自包含发布验证，完成信创目标机上线。

    与其他分组的关系¶

    • PLC 首页：UI 层的数据来源。ViewModel 依赖 IPlcLink 之类的抽象与通用报文 DTO，不直接引用具体驱动；协议替换不应改动本组任何页面。
    • C# 首页：async/await、Channel<T>、PeriodicTimer、record 等语言与运行时能力，是 MVVM 后台采集服务的基础。
    • Kylin V11：中文字体（Noto CJK）、fcitx5/ibus 输入法、高 DPI 缩放、无 GPU 时的软件渲染、linux-arm64 / linux-loongarch64 自包含发布都在该页落地。
    • 数据库首页：报警与历史曲线落库后，本组只负责展示，持久化与查询不放在 Avalonia 项目中。
