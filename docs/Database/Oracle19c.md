## 概述与核心概念

- **驱动**：`Oracle.ManagedDataAccess.Client`（NuGet 包 `Oracle.ManagedDataAccess.Core`）纯托管，不依赖本机 Oracle Client / Instant Client / `libclntsh`，是 Linux 与国产 CPU 上最省事的接入方式；具体能力「以实际安装的 NuGet 包版本为准」。
- **连接标识**：优先 EZCONNECT `//host:port/service_name`，绕开 `tnsnames.ora` 的查找路径与大小写问题。
- **核心对象**：`OracleConnection`、`OracleCommand`、`OracleParameter`、`OracleTransaction`；占位符 `:name`，类型用 `OracleDbType` 显式声明。
- **批量写入**：`ArrayBindCount` + 数组型参数「一次往返写整批」，比逐行 `ExecuteNonQuery` 更适合高频采集；攒批 → 单事务提交 → 失败整批回滚由上游重传。

## 连接与配置

连接串放配置里，密码走环境变量或密钥管理，不要硬编码：

```json
{
  "ConnectionStrings": {
    "Oracle": "User Id=collector;Password=***;Data Source=//10.0.0.8:1521/ORCLPDB1;Pooling=true;Max Pool Size=10;"
  }
}
```

高频写入表按「点位 + 时间」建复合索引，时间列用 `TIMESTAMP(3)` 保留毫秒：

```sql
CREATE TABLE tag_history (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    tag_id NUMBER(10) NOT NULL, sample_time TIMESTAMP(3) NOT NULL,
    value NUMBER NOT NULL, quality NUMBER(3) NOT NULL);
CREATE INDEX idx_tag_time ON tag_history(tag_id, sample_time);
```

!!! warning "绑定方式与迁移成本"
    ODP.NET 默认按**位置**绑定参数，多参数语句务必设 `cmd.BindByName = true`。采集 SQL 尽量只用标准 `INSERT`/`SELECT` 与通用类型，少用 PL/SQL 包与专有序列——信创改造时达梦、人大金仓的兼容模式并不通用连接串与 `OracleDbType`，需整体换 provider。

## 关键用法与代码示例

数组绑定批量写入：各参数数组长度必须与 `ArrayBindCount` 一致，异常时未提交事务随连接释放回滚：

```csharp
using Oracle.ManagedDataAccess.Client;

public sealed class OracleTagWriter
{
    private readonly string _cs;
    public OracleTagWriter(string cs) => _cs = cs;

    public async Task<int> WriteBatchAsync(
        IReadOnlyList<TagSample> samples, CancellationToken ct = default)
    {
        if (samples.Count == 0) return 0;
        await using var conn = new OracleConnection(_cs);
        await conn.OpenAsync(ct);
        using var tx = conn.BeginTransaction();
        await using var cmd = conn.CreateCommand();
        cmd.Transaction = tx;
        cmd.BindByName = true;
        cmd.CommandText =
            "INSERT INTO tag_history(tag_id, sample_time, value, quality) " +
            "VALUES(:tagId, :ts, :val, :quality)";
        cmd.ArrayBindCount = samples.Count;
        cmd.Parameters.Add(new OracleParameter("tagId", OracleDbType.Int32)
            { Value = samples.Select(s => s.TagId).ToArray() });
        cmd.Parameters.Add(new OracleParameter("ts", OracleDbType.TimeStamp)
            { Value = samples.Select(s => s.Timestamp).ToArray() });
        cmd.Parameters.Add(new OracleParameter("val", OracleDbType.Double)
            { Value = samples.Select(s => s.Value).ToArray() });
        cmd.Parameters.Add(new OracleParameter("quality", OracleDbType.Int16)
            { Value = samples.Select(s => s.Quality).ToArray() });
        var rows = await cmd.ExecuteNonQueryAsync(ct);
        tx.Commit();
        return rows;
    }
}

public sealed record TagSample(int TagId, DateTime Timestamp, double Value, short Quality);
```

## 常见坑与排查

| 现象 | 常见原因 | 处理 |
|---|---|---|
| `ORA-00936` / 参数不生效 | 用了 `@p` 占位符 | 改用 `:p`，并设 `BindByName = true` |
| 写入列错位 / 数组绑定报错 | 位置绑定、数组长度与 `ArrayBindCount` 不一致 | 保持 `Add` 顺序、统一用同一批 `samples` 投影 |
| 中文点位名乱码 | 库端字符集非 `AL32UTF8` | 托管驱动不读 `NLS_LANG`，核对库字符集 |
| 连接池耗尽 / 索引隐式转换 | 长事务未提交、未指定 `OracleDbType` | 缩短事务、及时 `Dispose`、显式声明类型 |

## 信创与跨平台注意事项

- **无原生依赖**：托管驱动不含平台原生库，规避国产 CPU（arm64 / loongarch64）上 Instant Client 缺包问题；.NET 8 运行时仍需对应架构构建，自包含发布按目标 RID 选择。
- **EZCONNECT 优于 tnsnames.ora**：Linux 无默认 `$ORACLE_HOME/network/admin`，路径与服务名大小写敏感；统一小写，`Data Source` 直接内联主机、端口、服务名。
- **国产库适配**：达梦、人大金仓、神舟通用各自提供 .NET 驱动，连接串键名、参数前缀、类型枚举均不同；在 Infrastructure 层定义 `ITagWriter` 让多实现并存，业务层不感知。
- **路径与脚本**：避免 `SEQUENCE.NEXTVAL` 内联与 Oracle 专有函数；部署脚本、日志目录、Wallet 路径在 Linux 下区分大小写，CI 与现场保持一致。
